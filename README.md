# 숏폼 사용 습관 개선 웹앱 🌱

숏폼 콘텐츠의 무의식적인 장시간 시청을 줄이고,
사용자가 일정 시간마다 휴식을 취하는 습관을 형성할 수 있도록 돕는 웹앱입니다.

단순히 사용 시간을 측정하거나 콘텐츠를 차단하는 것이 아니라,
휴식 미션과 성장형 보상 시스템을 통해 사용자가 스스로 건강한 디지털 사용 습관을 만들어가는 것을 목표로 합니다.

---

## 📌 프로젝트 개요

### 문제 정의

유튜브 쇼츠, 인스타그램 릴스 등 숏폼 콘텐츠의 사용 시간이 증가하면서
집중력 저하와 무의식적인 콘텐츠 소비 문제가 발생하고 있습니다.

기존 스크린타임 서비스는 사용 시간을 보여주거나 앱 사용을 제한하는 데 집중하고 있습니다.

저희는 사용자가 일정 시간마다 직접 휴식을 취하도록 유도하고,
휴식 행동에 대한 보상을 제공하는 방식으로 디지털 사용 습관을 개선하고자 했습니다.

---

## 🎯 주요 기능

### 1. 휴식 주기 설정

사용자는 숏폼 콘텐츠를 시청하기 전 원하는 휴식 주기를 설정할 수 있습니다.

- 15분
- 30분
- 45분
- 직접 입력

### 2. 숏폼 시청 타이머

사용자가 `시작하기`를 누르면 설정한 휴식 주기에 따라 타이머가 시작됩니다.

설정한 시간이 지나면 휴식 알림이 나타납니다.

### 3. 휴식 미션

휴식 시간에 간단한 미션을 수행할 수 있습니다.

- 계산 문제
- 구구단
- 기억력 게임
- 집중력 테스트
- 스트레칭 및 명상

미션을 완료하면 휴식 성공으로 기록됩니다.

### 4. 휴식 건너뛰기

사용자는 휴식을 건너뛸 수 있으며,
건너뛴 횟수 역시 기록하여 자신의 사용 습관을 확인할 수 있도록 했습니다.

### 5. 성장형 보상 시스템 🌱

휴식 성공 여부에 따라 사용자의 나무가 성장합니다.

`새싹 → 묘목 → 나무 → 큰 나무`

반대로 휴식을 계속 건너뛰면 나무의 건강도가 감소합니다.

### 6. 통계

사용자는 자신의 휴식 및 사용 습관을 확인할 수 있습니다.

- 총 시청 횟수
- 휴식 성공 횟수
- 건너뛰기 횟수
- 휴식 성공률
- 연속 성공 기록
- 나무 성장 상태
